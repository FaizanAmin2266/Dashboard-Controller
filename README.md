# Dashboard-Controller
A custom ESP32 hardware interface and firmware for reverse engineering and controlling a 2011 Ford Fusion instrument cluster.
<br> <br>

## Cluster Pinout
Pin 5 - Ground<br>
Pin 20 - 12V<br>
Pin 21 - 12V<br>
Pin 25 - HS_Can+<br>
Pin 26 - HS_Can-<br>
Pin 12 - MS_Can+<br>
Pin 13 - MS_Can-<br>
